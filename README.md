# A Little Note for Wissal

A small personalized question page from Leevay to Wissal. It has an animated letter opening, four questions, two answer choices, the selected anime image as its full-page background, and Bahjat's “Ethereal” as background music.

## Preview

Open `index.html` in a browser. Press “Open your little note” to reveal the questions and start the song if the browser blocked autoplay. Each answer advances to the next question. On desktop, “No” dodges the pointer up to four times per question, then stays put; on touch screens it can be tapped normally. Answers are only kept in page memory and are not sent or saved.

## Make it yours

The selected background is `assets/background.png` and the music file is `assets/ethereal.mp3`. Keep both beside `index.html` when publishing. To change the questions, edit the `questions` list near the bottom of `index.html`.

To share it as a link, this folder can be published with GitHub Pages. Connect the project to a GitHub repository, then enable Pages for the repository's main branch.
